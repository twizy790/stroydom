# СтройКонтроль CRM

Учебный проект CRM для строительной компании. Система помогает вести частные дома от начала работ до сдачи заказчику и связывает объекты, этапы, задачи, закупки и бюджет.

## Текущий этап

Подготовлен кликабельный макет CRM на React: обзор, объекты, клиенты, задачи, закупки, финансы, документы и настройки. В карточке объекта есть переключение этапов строительства с 2D-визуализацией фасада дома. Формы создания открываются, задачи можно отмечать выполненными.

Также добавлен первый ASP.NET Core Web API на C#. Сейчас API работает с демонстрационными данными в памяти процесса; подключение SQLite и сохранение данных запланированы следующим этапом.

## Технологии

- React + Vite — клиентское приложение.
- ASP.NET Core Web API на C# / .NET 10 — серверная часть.
- EF Core и SQLite — подключение базы данных запланировано.

## Запуск интерфейса

Требуется Node.js 20.19+ или 22.12+.

```bash
npm install
npm run dev
```

## Запуск API

Требуется .NET 10 SDK.

```bash
cd backend
dotnet run --no-launch-profile --urls http://localhost:5078
```

Основные маршруты API:

- `GET /api/health` — состояние API.
- `GET /api/clients` — список клиентов.
- `GET /api/projects` — список объектов.
- `GET /api/projects/{id}` — объект с этапами, задачами, закупками, расходами и документами.
- `POST /api/projects` — создание объекта с шестью этапами.
- `PATCH /api/tasks/{id}/status` — изменение статуса задачи.

## Основной сценарий

- Руководитель создаёт объект, привязывает клиента и задаёт этапы строительства.
- Прораб ведёт задачи и отмечает их выполнение.
- Закупки и расходы относятся к конкретному объекту и этапу.
- Прогресс объекта рассчитывается по выполненным этапам и задачам.
- Клиент видит прогресс и документы только своего объекта.
