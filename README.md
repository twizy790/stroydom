# СтройКонтроль CRM

Учебный проект CRM для строительной компании. Система помогает вести частные дома от начала работ до сдачи заказчику и связывает объекты, этапы, задачи, закупки и бюджет.

## Текущий этап

Подготовлен кликабельный макет CRM на React: обзор, объекты, клиенты, задачи, закупки, финансы, документы и настройки. В карточке объекта есть переключение этапов строительства с 2D-визуализацией фасада дома. Формы создания открываются, задачи можно отмечать выполненными. Данные демонстрационные, подключение ASP.NET Core API и сохранение данных запланированы отдельным этапом.

## Технологии

- React + Vite — клиентское приложение.
- ASP.NET Core Web API на C# — серверная часть (следующий этап).
- Entity Framework Core и реляционная база данных — хранение данных (следующий этап).

## Запуск интерфейса

Требуется Node.js 20.19+ или 22.12+.

```bash
npm install
npm run dev
```

## Основной сценарий

- Руководитель создаёт объект, привязывает клиента и задаёт этапы строительства.
- Прораб ведёт задачи и отмечает их выполнение.
- Закупки и расходы относятся к конкретному объекту и этапу.
- Прогресс объекта рассчитывается по выполненным этапам и задачам.
- Клиент видит прогресс и документы только своего объекта.
